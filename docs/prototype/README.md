# Homepage prototype

The design of the Firna homepage that the user approved on 2026-11-03. It
is the source for the homepage screen of milestone 1 of
`plans/firna-homepage.md`. That milestone ports it to shared components and
then removes this folder.

- `index.html`: the prototype page. Open it in a browser. `?many` shows 12
  projects. `?bg=opacity` shows plain panels, a review aid that the site
  does not keep, because the user chose the frosted panels.
- `notes.md`: the designer's notes: the grain field, the interaction, the
  contrast rules, and the performance budget.
- `logos/`: the Firna logo, mark, and favicon, and the five project logos.

The prototype loads its fonts from Google Fonts. The site hosts its fonts
itself, as the plan says.
